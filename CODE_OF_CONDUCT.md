# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment of any kind.
Disagreements are about code, not people.

Report unacceptable behavior privately to the maintainer,
[@dcotelo](https://github.com/dcotelo), via any contact listed on
[dcotelo.dev](https://dcotelo.dev).
Reports are handled confidentially. Consequences scale from a warning to a
permanent ban from the project at the maintainer's judgment, following the
Covenant's enforcement guidelines.
